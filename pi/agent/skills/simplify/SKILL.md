# Simplify

Keep this skill explicit-only: invoke `/skill:simplify` with the concrete pre-implementation artifact or approach to assess.

Read [the shared assessment procedure](../challenge/references/protocol.md) completely and apply its **simplification** lens. Identify what can be removed, merged, or deferred while preserving required outcomes, acceptance criteria, constraints, and material safeguards. Retain necessary complexity and check against underengineering; brevity alone is not success.

Do not also run a general risk assessment unless requested. Do not edit or replace the target unless revision is explicitly authorized. Use `review` for completed code or behavior.
