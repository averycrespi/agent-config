# Explicit recovery and handover

Require actual user takeover authority and evidence that the former coordinator relinquished control or is inactive before issuing worker controls. A loaded index, released label or absent discovery result is not proof of liveness. If the former coordinator is still active, coordinate explicit relinquishment; do not create a competing controller or send diagnostic prompts. Ownership is procedural, not enforced fencing. Preserve every child owner.

1. Read the existing index and its original agreement/handover authority. Reconcile repository/common-dir identity, former/current coordinator and scope; do not initialize a new index over missing/corrupt facts. Stop affected control actions on conflict while retaining resources and adverse evidence.
2. Inspect active assignments by brief and current child coordination section. Match assignment/revision, run/session/incarnation, Herdr occupant, checkpoint owner/checkout and Git branch/head. Read completed history only when its accepted reference is needed or inconsistent; do not reload every past test/report.
3. Reconcile all pending human questions independently. Preserve request IDs/context, cancellation and actual answer provenance. Two unanswered questions remain pending while a third qualified result can be accepted. Do not re-ask merely because the coordinator changed. Correlate direct intervention before applying an older answer.
4. Inspect unresolved launch/start/prompt/pause effects against actual resources and the existing child's report. Submission alone is not execution/application. Missing scrollback or receipt never proves non-delivery; retain uncertain intent instead of relaunching/resending. Require concrete reconciliation before another effect on that assignment.
5. Recover original observer receipts and pre-registration intent references, exact membership/coverage, attempted handoffs and reserved allowances. Cancel/reconcile only owned old observers where necessary and authorized. Account known host attempts mechanically once; preserve unknown reservations and absolute deadline. Do not copy or reset child CI/repair budgets.
6. Record explicit owner transfer with instruction and prior-control evidence references in Owner and authority, along with changed gaps/next actions at the same safe boundary. Transfer never qualifies stale evidence or grants missing publication/control scope.
7. Only after reconciliation restore bounded attention for proven ongoing authorized workers inside retained allowances. Resolve live incarnation freshly; register before continuation and read child state once after ACK. Never promise detached supervision while Pi is closed. Return precise blockers for unresolved identities/effects; unrelated reconciled assignments may proceed if authority remains.

For a planned handover, the outgoing coordinator first stops new control, reconciles owned observers and pending effects, preserves durable evidence and identifies next actor/action. Mark relinquishment only after control is settled. If a question/control remains unresolved, preserve it explicitly; relinquishment must not imply the child released ownership or ceased writes. Report requested pause versus confirmed quiescence honestly. No automatic worker adoption, cleanup, stack migration or budget renewal occurs.
